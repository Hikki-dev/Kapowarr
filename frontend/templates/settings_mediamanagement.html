File Naming

Instead of removing illegal characters from the filename, replace them smartly with a dash. Depending on the place, spaces might be put before, after or around the dash.

The naming format for the volume folder.

Available variables are: {series_name}, {clean_series_name}, {volume_number}, {comicvine_id}, {year}, {publisher} and {special_version}

The naming format for the file itself.

Available variables are: {series_name}, {clean_series_name}, {volume_number}, {comicvine_id}, {year}, {publisher}, {issue_comicvine_id}, {issue_number}, {issue_release_date}, {issue_release_year} and {issue_title}

The naming format for the file itself if there is no issue title.

Available variables are: {series_name}, {clean_series_name}, {volume_number}, {comicvine_id}, {year}, {publisher}, {issue_comicvine_id}, {issue_number}, {issue_release_date} and {issue_release_year}

The naming format for the file itself (if it's a special version, like a one shot, tpb or hard cover).

Available variables are: {series_name}, {clean_series_name}, {volume_number}, {comicvine_id}, {year}, {publisher} and {special_version}

The naming format for the file itself (if it's a Volume As Issue, so an issue named "Volume N").

Available variables are: {series_name}, {clean_series_name}, {volume_number}, {comicvine_id}, {year}, {publisher}, {issue_comicvine_id}, {issue_number}, {issue_release_date}, {issue_release_year} and {issue_title}

Whether or not to use, for example, 'One-Shot' instead of 'OS'. The term 'TPB' will always stay 'TPB'.

Folders

Create missing volume folders during file scan.

Delete empty folders in the volume folder during file scan. If "Create Empty Volume Folders" is disabled and the volume folder is empty, it'll also be deleted.

File Management

Issues deleted from disk are automatically unmonitored.

Set date of file. Save the settings before using the button below.

Permissions applied to the folders and files (without execute bits). Give value in octal (e.g. '755'), or leave empty to disable. Save the settings before using the button below. Only works on Unix systems.

Ownership group applied to the folders and files. Give group name or ID (e.g. 'media' or '1001'), or leave empty to disable. Save the settings before using the button below. Only works on Unix systems.

Converting

The "Converting" feature allows you to change the format of your files (e.g. from cbr to cbz). Extracting archive files also falls under "converting".

After a file is downloaded, automatically convert it to the format you prefer (if a format preference is set). This changes the format of files, so leave it off if you want to keep them as they are.

If a downloaded .zip or .rar has complete issues inside (CBZ, CBR or PDF files), take the issues out and file them in the library. This works by itself, without the setting above, and never changes the format of a file. The archive is checked first, nothing in your library is overwritten, and the archive is only deleted once its issues are in the library.

Put the details ComicVine gave Kapowarr (series, issue number, title, summary, release date, publisher, link) inside every CBZ as a ComicInfo.xml, and write a series.json and a cover in the series folder, so Komga and Kavita show the right names, numbers, summaries and covers. A file that already has its own ComicInfo.xml is left alone, and CBR or PDF files are matched by their name instead.
